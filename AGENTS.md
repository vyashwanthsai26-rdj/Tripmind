# TripMind Project Instructions

TripMind is an AI travel planner that remembers user preferences,
budgets, dislikes, travel style, and previous trips.

Planned architecture:
React frontend -> Node.js/Express backend -> MongoDB + Hindsight + LLM.

MongoDB stores application data.
Hindsight handles long-term AI memory.
The LLM generates personalized travel plans.

Keep the project simple, modular, secure, and beginner-friendly.
Never hardcode API keys or secrets.
Do not invent Hindsight API methods; verify the installed/current documentation.
